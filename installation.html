Prêt à l'emploi en 2 minutes

Installez Jarvis Agency sur n'importe quel ordinateur portable ou fixe sans manipulation complexe.

L'option la plus simple pour Windows 10 & 11

Un exécutable unique compilé qui intègre le serveur FastAPI, l'interface graphique Chromium OLED, Faster-Whisper et SQLite.

  1. Étape 1 : Installez Ollama (le moteur d'inférence gratuit).
  2. Étape 2 : Téléchargez l'exécutable JarvisAgency.exe.
  3. Étape 3 : Double-cliquez pour lancer. Le modèle adapté à votre carte graphique est automatiquement prêt !
📥 Télécharger JarvisAgency.exe (v2.0) 92 Mo • 100% Hors-ligne
Vérification rapide Ollama
# Vérifiez qu'Ollama est actif sur votre machine :
curl http://127.0.0.1:11434/api/version

# Téléchargez le modèle par défaut recommandé (Llama 3.1) :
ollama run llama3.1:8b

Installation 100% Automatisée en 1 commande

Ce script détecte votre GPU NVIDIA / AMD / Intel, installe les dépendances nécessaires, configure le modèle idéal et lance Jarvis Agency.

PowerShell (Admin ou Utilisateur)
irm https://raw.githubusercontent.com/ayoub/jarvis-agency/main/install.ps1 | iex
Ce que fait le script :
[1/4] Détection GPU : Calcul de la VRAM disponible
[2/4] Vérification Ollama : Téléchargement automatique si absent
[3/4] Pull du modèle optimal : llama3.1:8b ou phi3:mini
[4/4] Démarrage immédiat de Jarvis Agency Studio

Déploiement pour Développeurs & Linux

Clonez le dépôt Git pour lancer le backend FastAPI directement dans un environnement virtuel Python ou via conteneur.

Commandes Terminal
git clone https://github.com/ayoub/jarvis-agency.git
cd jarvis-agency

python -m venv .venv
source .venv/bin/activate  # ou .venv\Scripts\activate sur Windows
pip install -r requirements.txt

# Lancement du serveur sur toutes les interfaces :
uvicorn backend.server:app --host 0.0.0.0 --port 9099
Variables d'environnement facultatives
OLLAMA_HOST=http://127.0.0.1:11434
DEFAULT_AGENT=auto
PORT=9099
CORS_ORIGINS="*"
