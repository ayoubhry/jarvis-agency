Installer et lancer J.A.R.V.I.S. Agent OS

Une arborescence simplifiée autour d'un exécutable unique JarvisAgency.exe, sans Python requis pour l'utilisateur final.

Exécutable autonome pour Windows 10 & 11

Intègre le lanceur PyWebView Edge WebView2, FastAPI WebSockets, Faster-Whisper CPU, NVML en mémoire, UI Automation et les 17 outils dans un seul binaire.

  1. Étape 1 : Installez Ollama (ou LM Studio) et récupérez qwen2.5:7b.
  2. Étape 2 : Vérifiez votre .env à côté de JarvisAgency.exe (ou générez-le dans Outils & Sécurité).
  3. Étape 3 : Double-cliquez sur JarvisAgency.exe. Le HUD OLED se positionne à droite sans déborder de la barre des tâches et Ollama pointe automatiquement sur models/.
📥 Accéder aux Releases GitHub (v3.0) ~204 Mo • WebView2 • Port 127.0.0.1:9099
Structure du dossier IA Local/
IA Local/
├── JarvisAgency.exe   # Double-clic pour démarrer
├── .env               # FAST_MODEL=qwen2.5:7b, VISION_MODEL=qwen2.5vl:7b
├── data/              # agency.db (WAL), macros.json, webview_cache
├── models/            # Poids locaux Ollama (OLLAMA_MODELS)
└── src/               # Code source Python & frontend

Exécuter directement depuis src/

Idéal pour modifier les prompts dans core/react_loop.py, ajouter un outil dans tools/ ou personnaliser le HUD OLED.

PowerShell depuis src/
cd "IA Local\src"
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Lancer le HUD desktop complet (FastAPI + PyWebView) :
python app.py
Vérifier Ollama & modèles locaux
# Modèle rapide par défaut :
ollama pull qwen2.5:7b

# Optionnel pour captures écran multimodales :
ollama pull qwen2.5vl:7b

# Vérifier l'API locale :
curl http://127.0.0.1:11434/api/tags

Recompiler l'exécutable JarvisAgency.exe

Le fichier src/JarvisAgency.spec embarque les modules core, vision, tools, voice, backend, frontend et l'icône sans fenêtre console (console=False).

Build PyInstaller
Stop-Process -Name "JarvisAgency" -Force -ErrorAction SilentlyContinue
cd "IA Local\src"
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm JarvisAgency.spec
Move-Item -Force .\dist\JarvisAgency.exe ..\JarvisAgency.exe
Points techniques du packaging
• Démarrage séquentiel /api/ping -> PyWebView CLR
• Télémétrie GPU directe via nvml.dll (0 popup CMD)
• Ollama lancé avec CREATE_NO_WINDOW seul
• Exclusion capture WDA_EXCLUDEFROMCAPTURE

Piloter votre Chrome ouvert & Raccourcis HUD

Pour laisser J.A.R.V.I.S. agir dans vos onglets déjà connectés via Playwright, lancez Chrome avec le port de débogage 9222 et renseignez CHROME_CDP_URL dans ⚙️ Config.

Lancer Chrome avec port CDP
chrome.exe --remote-debugging-port=9222
Raccourcis clavier J.A.R.V.I.S.
Ctrl + Espace     : Maintenir pour dicter (Whisper CPU)
Ctrl + Shift + X  : Kill Switch d'urgence global
Bouton ▶ Réarmer  : Réactive l'agent après un STOP
Souris coin (0,0) : FailSafe matériel PyAutoGUI
