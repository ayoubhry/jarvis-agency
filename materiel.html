Budget VRAM & Sélection du Modèle

J.A.R.V.I.S. sépare intelligemment FAST_MODEL et VISION_MODEL dans .env, conserve Faster-Whisper sur CPU (int8) et se replie proprement sur le texte + UIA tant qu'aucun modèle Vision n'est téléchargé.

🎛️ Simulez votre configuration GPU / RAM :
Sélectionnez votre matériel pour afficher les modèles Qwen 2.5 / Qwen 2.5 VL recommandés.
CONFIGURATION ACTIVE RTX 3070 / 4060 (8 GO VRAM)
Modèles Recommandés :
qwen2.5:7b (Texte + UIA) ou qwen2.5vl:7b (Vision Unifiée)
qwen2.5:7b (~4,7 Go) répond instantanément avec UI Automation pour piloter les applications Windows. Pour l'analyse visuelle de captures mss, installez qwen2.5vl:7b (~5,6 Go) en 1 clic dans ⚙️ Config. Faster-Whisper reste sur CPU int8 (0 Mo VRAM).
55 - 75 tokens / sec
4,7 - 5,6 Go VRAM occupée
100% GPU + Whisper CPU Zéro swap VRAM/RAM
Commande Ollama (stockage local IA Local/models) :
ollama pull qwen2.5:7b # ou qwen2.5vl:7b pour la Vision
📥

Téléchargement Vision en 1 clic

Dans le HUD, le menu ⚙️ Config affiche les modèles réellement détectés dans IA Local/models et permet de télécharger qwen2.5vl:7b en direct via SSE (/api/models/pull).

📊

Télémétrie NVML sans console

La barre de statut lit température, charge GPU et VRAM directement en mémoire via nvml.dll (ctypes) toutes les 2 secondes : précision temps réel et aucune fenêtre terminal parasite.

🧹

Libération VRAM instantanée

Un bouton dédié appelle unload_vram_models() (keep_alive=0 sur Ollama) afin de vider immédiatement la VRAM à 0 % lorsque vous lancez un logiciel 3D ou un jeu.
