⚙️ Architecture Technique

Comment Jarvis Agency est construit

Une architecture locale de pointe, pensée pour éliminer les dépendances cloud et garantir des temps de réponse instantanés.

🧠

Moteur d'Inférence Découplé

Compatible avec Ollama et Llama.cpp. Exploite directement les cœurs Tensor NVIDIA (CUDA) ou l'accélération AVX2 des processeurs modernes pour streamer à plus de 60 tokens/seconde sans envoyer un seul octet sur Internet.

  • Format : GGUF quantifié 4-bit / 8-bit
  • Moteur : Ollama API locale (port 11434)
  • Confidentialité : 100% hors-ligne
⚡

Backend Asynchrone FastAPI & SSE

Noyau Python ultra-rapide gérant le Server-Sent Events (SSE), la mémoire SQLite relationnelle persistante, les sessions multi-onglets, l'analyse de fichiers (PDF, CSV, PCAP, Code) et la télémétrie matérielle en direct (VRAM, Température, GPU Util).

  • Serveur : FastAPI + Uvicorn
  • Mémoire : SQLite Vectoriel + Souvenirs
  • Réseau : Écoute 0.0.0.0:9099 (LAN ready)
🖥️

Client Desktop Windows Autonome

Packagé avec PyInstaller et PyWebView en un exécutable standalone de 90 Mo. Zéro installation de Python requise sur la machine de destination : double-cliquez sur JarvisAgency.exe et le serveur démarre en tâche de fond avec interface native.

  • Moteur Web : Microsoft WebView2 (Edge Chromium)
  • Packaging : Single-File .EXE sans installeur
  • Poids : Compact & optimisé
📱

Écosystème Mobile Android & PWA

Accédez à votre IA locale depuis votre smartphone. Application native Android JarvisAgency.apk (90 Ko, signée v2/v3) avec mémorisation de l'IP du PC, support du micro vocal et interface responsive optimisée OLED noir.

  • APK : WebView Native matérielle accélérée
  • PWA : Installable en 1 clic via Chrome
  • Connexion : Wi-Fi local avec QR Code

🚀 Déploiement Clé en Main

Prêt à l'emploi en 2 minutes

Installez Jarvis Agency sur n'importe quel ordinateur portable ou fixe sans manipulation complexe.

L'option la plus simple pour Windows 10 & 11

Un exécutable unique compilé qui intègre le serveur FastAPI, l'interface graphique Chromium OLED, Faster-Whisper et SQLite.

  1. Étape 1 : Installez Ollama (le moteur d'inférence gratuit).
  2. Étape 2 : Téléchargez l'exécutable JarvisAgency.exe.
  3. Étape 3 : Double-cliquez pour lancer. Le modèle adapté à votre carte graphique est automatiquement prêt !
📥 Télécharger JarvisAgency.exe (v2.0) 92 Mo • 100% Hors-ligne

ollama run llama3.1:8b

Déploiement pour Développeurs & Linux

Clonez le dépôt Git pour lancer le backend FastAPI directement dans un environnement virtuel Python ou via conteneur.

Commandes Terminal
git clone https://github.com/ayoub/jarvis-agency.git
cd jarvis-agency

python -m venv .venv
source .venv/bin/activate  # ou .venv\Scripts\activate sur Windows
pip install -r requirements.txt

# Lancement du serveur sur toutes les interfaces :
uvicorn backend.server:app --host 0.0.0.0 --port 9099
Variables d'environnement facultatives
OLLAMA_HOST=http://127.0.0.1:11434
DEFAULT_AGENT=auto
PORT=9099
CORS_ORIGINS="*"
