Version 3.0 Agent OS • 100% Local • Vision mss + UIA • Contrôle HITL

Votre Agent OS Local :
Il voit l'écran, et il agit sur votre PC.

Fini le simple chatbot passif : J.A.R.V.I.S. Agent OS observe votre bureau Windows en temps réel (mss + UI Automation), enchaîne jusqu'à 10 étapes via une boucle ReAct à 17 outils modulaires, écoute votre voix sur CPU (0 Mo VRAM) et protège chaque action sensible par validation humaine.

📥 Installer JarvisAgency.exe Windows 10/11 • Standalone (~204 Mo) 🛡️ Outils & Sécurité HITL 17 outils + générateur .env 🎛️ Simulateur GPU / VRAM Ollama • LM Studio • RTX 3070
👁️ Capture mss < 30 ms + UIA
🛡️ Validation HITL & Kill Switch Ctrl+Shift+X
🎙️ Voix Whisper CPU (0 Mo VRAM)
🪟 HUD OLED exclu de la capture (WDA)
