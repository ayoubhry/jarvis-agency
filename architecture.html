Comment J.A.R.V.I.S. Agent OS fonctionne

Six briques découplées autour d'un lanceur PyWebView séquentiel, conçues pour éliminer tout blocage de démarrage et toute ouverture parasite de console.

🧠

Noyau ReAct & Sécurité (core/)

react_loop.py pilote la boucle asynchrone (jusqu'à 10 étapes). llm_client.py gère Ollama & LM Studio sous mutex _OLLAMA_START_LOCK avec repli texte+UIA si le modèle Vision n'est pas encore installé.

  • Sécurité : HITL asyncio + FailSafe
  • Kill Switch : pynput Ctrl+Shift+X
  • HUD Win32 : WDA + EnumWindows / SetWindowPos
👁️

Perception Hybride (vision/)

screen.py capture l'écran via mss en moins de 30 ms et redimensionne en 1280×720 JPEG (78%) pour économiser la VRAM. accessibility.py parcourt l'ordre Z (GW_HWNDNEXT) en ignorant le HUD pour extraire jusqu'à 45 éléments UIA.

  • Capture : mss DPI-aware
  • UIA : comtypes (45 contrôles max)
  • Exclusion : WDA_EXCLUDEFROMCAPTURE
🛠️

17 Outils Modulaires (tools/)

registry.py génère automatiquement les schémas OpenAI Tool Calling : souris/clavier pyautogui, résolution de raccourcis Bureau/Menu Démarrer .lnk, Playwright/Chrome CDP et macros déclaratives JSON.

  • Desktop : clics, saisie UTF-8, raccourcis
  • Web : Playwright / Chrome CDP + ddgs
  • Macros : data/macros.json
🎙️

Pipeline Vocal CPU (voice/)

Reconnaissance vocale (stt.py) via Faster-Whisper (tiny, cpu, int8) consommant 0 Mo de VRAM GPU. Synthèse vocale (tts.py) par Piper ONNX local avec repli Windows SAPI5 (pyttsx3) ou edge-tts.

  • Raccourci : Ctrl+Espace (Maintenir)
  • STT : Faster-Whisper CPU int8
  • TTS : Piper / SAPI5 hors-ligne
⚡

Serveur FastAPI & NVML (backend/)

Streaming bidirectionnel WebSocket /ws/agent, endpoint ultra-rapide /api/ping, SSE /api/models/pull, base relationnelle SQLite WAL (data/agency.db) et télémétrie GPU lue en mémoire via nvml.dll sans jamais lancer nvidia-smi.exe.

  • Écoute : 127.0.0.1:9099 (WebSocket)
  • Mémoire : SQLite WAL + Souvenirs
  • Télémétrie : ctypes nvml.dll (0 popup)
🖥️

HUD Desktop Autonome (app.py)

Compilé en un exécutable unique JarvisAgency.exe (~204 Mo) avec PyInstaller et PyWebView WebView2 : démarrage séquentiel vérifiant /api/ping avant le CLR .NET, cache persistant dans data/webview_cache et mode docké 410 px ou plein écran.

  • Moteur : Edge WebView2 (WinForms)
  • Position : SPI_GETWORKAREA + DPI clamp
  • Poids : ~204 Mo standalone

Flux d'exécution temps réel sans blocage

1 • Interface HUD

app.py + frontend/

Le HUD OLED communique par WebSocket (/ws/agent) avec boutons compacts, Journal d'actions dépliable, modale ⚙️ Config et bouton STOP / ▶ Réarmer.

2 • Orchestration

backend/ + core/

run_react_agent alterne observation écran (si intention visuelle), inférence streaming et pause HITL avant toute action sensible ou critique.

3 • Modèles & OS

Ollama / LM Studio + Windows

Ollama pointe automatiquement sur IA Local/models (CREATE_NO_WINDOW seul), tandis que vision/ et tools/ agissent sur le bureau sans jamais ouvrir de terminal CMD.
